Metis Agent plans the change, then verifies it.

An autonomous coding agent for developers who want the codebase, the models, and the machine to stay their own.

Repository

Metis explores the repository, plans the change, edits files, runs tools, and verifies the result. Every call and result stays visible in the terminal.

It runs local models through Ollama, llama.cpp, LM Studio, or llama-prism, and can point at OpenAI, OpenRouter, Groq, Together, or another compatible endpoint.

02 / 03 Emulation / C++17

NESesis rebuilds the NES one bus cycle at a time.

A cycle-conscious NES/Famicom emulator. The bus and iNES cartridge parser are in place; the 6502 core, PPU, and APU are under active development.

Repository

The project starts at the memory map, not the screen. A 2 KB RAM mirrored through $1FFF, PPU and APU registers, OAM DMA, controller ports, and cartridge space all sit on one bus.

The test harness synthesizes byte-perfect iNES images in memory with sentinel values, so off-by-one parser and mapper errors fail loudly. No copyrighted ROMs are tested.

03 / 03 Local AI infrastructure

ollX gives a local model a local interface.

A self-hosted web interface for Ollama: streaming chat, image attachments for vision models, model management, and per-user history in SQLite.

Repository

The frontend is Svelte and Vite; FastAPI proxies Ollama’s HTTP API, streams chat over SSE, and keeps users and sessions in SQLite. The interface ships light and dark monochrome themes.

Generation settings expose temperature, top-p, max tokens, repeat penalty, and a system prompt. Models can be pulled and deleted from the interface.

04 / 06 Method

I learn systems by rebuilding them.

The useful abstraction is the one I can reconstruct. I work down the stack — from a 6502 bus and a cartridge header to Go agent loops and local inference servers — until the system is legible in both directions.

That is why the work looks like this: source first, then a working model of the machine beneath it.

01

Read the source

Start with the memory map, the protocol, or the loop. Find the contract before the interface.

02

Rebuild the layer

Write the smallest system that can carry the same behavior, then make it exact.

03

Test the behavior

Run the test, inspect the result, and keep the proof in the repository.
